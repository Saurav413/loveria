# Loveria - Long Distance Couple App

## Folder Structure

- `src/`: Main source code.
    - `components/`: UI components (common, layout, specific modules).
    - `features/`: Modularized feature logic (chat, memories, countdown).
    - `hooks/`: Custom React hooks.
    - `services/`: API and third-party service integration (Firebase).
    - `store/`: State management.
    - `utils/`: Utility functions.
    - `assets/`: Images, icons, and fonts.
    - `styles/`: Global styles and themes.
- `public/`: Static assets.
- `tests/`: Automated tests.
- `docs/`: Documentation.
